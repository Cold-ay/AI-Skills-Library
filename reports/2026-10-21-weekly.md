### 1. humanizer: include

- **Use:** Rewrites AI-sounding text so it reads as written by a person, without changing what it says. It works from a pattern catalogue based on Wikipedia's "Signs of AI writing", with before/after examples. Use it on drafts, docs, and release notes before publishing.
- **Category:** `writing-editing`, added for this skill.
- **Maintenance:** HEAD `8c307f367c91bd974002f10f2be2965d642c13df`, 2026-10-17 03:12 HKT
- **License:** MIT (root). No exceptions found at root.
- **Install:** `/plugin install humanizer@humanizer` (Claude Code ≥2.1.142); `npx skills add blader/humanizer --global --agent codex`
- **Risks:** Instructions only. `scripts/validate-package.py` is for packaging and is not needed by the skill. SKILL.md states no credentials or network use.
- **Codex:** upstream-claimed. Evidence: https://github.com/blader/humanizer/blob/8c307f367c91bd974002f10f2be2965d642c13df/README.md ("### Codex")
- **Reason:** Specific input and output, instruction-only, and an explicit MIT license.
