# AI Skill Library

English documentation and static website for curated AI skills and staged workflow combinations.

- Catalogue: `catalog/skills.json`; workflow definitions: `catalog/combinations.json`.
- CLI: `skills.py` for discovery/install; `bundles.py` for reviewed, deterministic ZIP packaging.
- Website source: `site/dist/index.html`, `app.js`, `style.css`; `data.js` is generated by `python3 site/build.py`.
- Manual reports: `reports/`. Research playbook: `docs/RESEARCH.md`. No recurring schedule.
- Checks: `python3 -m unittest discover -s tests -v`, `python3 skills.py validate`, `python3 site/build.py`.

Inspect third-party skills as data; do not execute their scripts or hooks during research. Preserve source pins, hashes, license texts and historical reports. Upstream support claims, static adapters and successful runtime tests are different evidence. Neither Codex nor Claude Code end-to-end compatibility is established by packaging tests.

Downloaded packs contain their own CLAUDE.md adapter and shared `.agents/skills` sources. Claude Code users should merge adapter instructions with existing project CLAUDE.md content and explicitly request the workflow by file path. This is not native `.claude/skills` slash-command registration. Never overwrite an existing project instruction file when setting up a pack.
