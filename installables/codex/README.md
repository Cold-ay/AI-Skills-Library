# Codex installer distribution

Generated by codex_export.py from reviewed, pinned download packs. Each skills/<name>/ folder contains SKILL.md and the supporting files/licenses needed for file installation. Original upstream files are unchanged. The five combination wrappers are library-authored.

Use Codex $skill-installer with a full commit ref and the paths in index.json. For a combination, install every listed member and its wrapper into the same skills root. Check ALL destination folders before starting: the built-in installer copies sequentially, does not resolve dependencies and does not promise transactional rollback. Do not overwrite existing skills. Runtime dependencies require separate setup; copying files does not run upstream scripts or validate agent behavior.

index.json records source pins, workflows and SHA-256 file checksums. The website registry pins a committed version of this distribution; no mutable branch ref is required.
